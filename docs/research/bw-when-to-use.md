# 黑白滤镜何时该推——研究备忘

## 核心原则
**色彩即主体时，绝不推黑白。**

## 适合黑白的正面条件
1. **强对比光影**：侧光/逆光形成的明暗分割（lr>1.8）
2. **建筑/几何线条**：对称建筑、街拍纪实（manmadeScore高）
3. **纹理质感**：岩石/树皮/织物等纹理占主导
4. **真·近单色**：sat<0.04 且无暖色无肤色（本来就是灰的）
5. **纪实街拍**：突出叙事而非色彩

## 必须避开黑白的负面场景
| 场景 | 原因 |
|---|---|
| 美食（food） | 暖色=食欲，黑白毁情绪 |
| 晚霞（sunset） | 橙金=主体，黑白全毁 |
| 人像（portrait） | 肤色=主体，普通光不推黑白 |
| 鲜艳风光（velvia场景） | 红蓝对撞是卖点 |
| 宠物暖光 | 暖色氛围 |

## 人像黑白的例外
- **侧光强对比人像**（lr≥2.0）→ portrait-mono 可推
- **普通暖光人像** → 走 portrait-warm/portra，绝不推 mono

## 打分修正要点
- sat<0.06 加黑白候选：仅限 architecture/street/general
- food/sunset/portrait 场景：mono/mono-warm 直接 -30
- 真·近单色（sat<0.04 无暖色无肤色）：通用池可推黑白
