# M: 移动端性能/体验

## 现状问题
1.9MB HTML 在弱网/老设备首屏慢；PWA 更新提示不明显；离线可用性未充分验证。

## 可落地项

### 1. PWA 更新提示（~20行）
- sw.js 检测到新版本时 postMessage → UI 顶部出现"有新版本，点击刷新"条
- 现状：已有 sw 注册但无用户提示
- 验收：更新后用户看到提示

### 2. 离线可用性验证（已有基础）
- sw.js 已 cache index.html + 核心资源
- 需验证：断网后能否打开、分析功能是否降级为本地
- 验收：断网打开 PWA 不白屏

### 3. 老设备降级
- iOS Safari 14-15：无 OffscreenCanvas、无 WebGPU
- 现状：ORT wasm 兜底已有
- 补充：分析耗时>5s 时显示"正在分析..."加载态
- 验收：慢设备不卡死

### 4. 内存保护
- 12MP 图已降采样到 2048px
- 补充：连续分析5张以上后释放旧图引用
- 验收：长时间使用不 OOM

### 5. 弱网云端超时
- 云端 fetch 超时 15s → 自动降级本地
- AbortController 已有
- 验收：弱网不卡

## 优先级
1. PWA 更新提示（用户能感知到版本更新）
2. 离线验证
3. 分析加载态
