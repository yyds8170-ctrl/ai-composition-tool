# L: 失败模式库 — 防御规则

## 从139+24张回归图归类

| 失败类型 | 症状 | 防御规则 | 落点 |
|---|---|---|---|
| 极暗图(<10%亮度) | 边缘检测失效，误裁 | 平均亮度<15 → noCrop | analyzePixels guard |
| 高反差(逆光) | 质心偏亮部，裁掉暗部主体 | 亮度方差>0.4 → 缩小裁切量 | cropGuard |
| 重复纹理(砖墙/草地) | 边缘能量均匀，误判无死区 | 局部纹理方差/全局方差>3 → 怀疑重复纹理，noCrop | textureSignal |
| 文字截图 | 全是高对比边缘，误判为"丰富" | 边缘密度>0.4且饱和<0.1 → 截图模式，noCrop | screenshotDetect |
| 多人像 | 质心在两人中间，裁掉一人 | 人脸检测已有，faceCount>1 → 扩大保护框 | faceGuard |
| 极端比例(超宽全景/超长竖图) | 裁切方向误判 | 宽高比>2.5或<0.4 → 只允许小范围优化 | aspectGuard |
| 纯灰/纯色图 | 所有信号为0，误触发 | 饱和度<0.05且方差<0.02 → noCrop | blankDetect |

## 优先级
1. 极暗图 noCrop（最简单最常见）
2. 文字截图 noCrop（避免乱裁截图）
3. 纯灰/纯色图 noCrop（边界输入保护）

## 验收测试
- 合成极暗图：不裁
- 合成截图：不裁
- 合成纯灰图：不裁
