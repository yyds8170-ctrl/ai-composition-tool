## 3. 还能怎么优化（v12.29 候选）

1. **满框主体的人工出口**：对"满框宠物/美食/车"在结果面板给一个"AI 再找一个构图"按钮，允许用户主动尝试 4:5/16:9（默认不自动切主体）。
2. **云端 prompt 压缩 + 非人像模型路由**：max_tokens 已降到 1000，下一步压 system prompt 约 30%，并对非人像 20 张 A/B 更快的视觉模型；目标 p90≤20s。
3. **Face Landmarker 468 点**：人像 headroom/eye-line/闭眼检测；30 张专项 A/B 后决定是否上线。
4. **YOLO26n**：需要官方 ONNX 导出与后处理改造；先做 100 图检测 A/B，不通过不换。
5. **NIMA/TOPIQ 候选排序**：模型转换/许可确认后，用于多个裁切候选的美学排序，不替代规则护栏。
6. **场景误判专项**：sky/water/street 被 Lab 弱标签误判的样本，用 VLM 语义 + 本地证据融合，目标场景一致率提升。

## 4. 结论

v12.28 解决了 v12.27 最大的两个问题：
- **街景/建筑里有人就整张不裁** → 人景共存安全裁切，人物安全边 0 切穿；
- **云端宠物/美食 40%+ 激进裁切** → 分级保护，动物≤8%/25%、美食≤12%/35%、人像≤10%。

本地 57% 主动裁切，剩余 43% 主要是人像/满框宠物/美食/极暗保护，属于"宁可不裁也不切主体"的合理保守。下一版不再盲目提高裁切率，而是给满框主体一个人工出口、继续压云端时延、并做端侧模型 A/B。
