# K: 对比/分享 UX 打磨

## 现状问题
对比滑块只有手动拖动，分享/存作品流不清晰。

## 高价值低工作量改进

### 1. 长按对比（最优先，~20行代码）
- 在对比模式下，按住任意位置 = 显示原图，松手 = 效果图
- 实现：pointerdown 时 cmpPos=0%，pointerup 时恢复
- 对标：Snapseed/VSCO 标准交互
- 验收：长按松开后画面正确恢复

### 2. 自动循环对比（~30行）
- 对比模式加"自动"按钮，cmpPos 在 0-100% 间匀速循环 3 秒
- 适合社交展示
- 实现：rAF 插值

### 3. 百分比指示（~10行）
- 拖动时在把手上方显示 "20% / 80%" 文字
- 对标：Lightroom

### 4. 保存后分享卡片（~50行）
- 保存成功后弹"已保存到相册" + 分享按钮
- 生成带滤镜效果的 JPEG 直接下载
- 不做社交 API 集成（单文件限制）

### 5. 对比方向提示（~5行）
- 首次开对比时短暂动画：从左滑到右一次
- 教用户这是可拖动的

## 优先级
1. 长按对比（最高ROI）
2. 百分比指示
3. 自动循环对比
