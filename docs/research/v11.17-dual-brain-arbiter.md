## 2. P1 修正详述

### P1-4：硬保护前置（否决不裁）vs 护栏层（减裁）——两条不同的线

| | 硬保护（仲裁器开头） | 护栏层（仲裁器之后） |
|---|---|---|
| 触发 | 人脸/关节/物体边界/高彩显著性命中 | 所有已出框的二次微减 |
| 动作 | **直接输出 crop=Z（[0,0,0,0]），不裁** | 只把裁边值调小，不新增裁边 |
| 调用顺序 | 仲裁器**第一条**（在 R1-R7 之前） | 仲裁器产出 crop0 之后 |
| 依据 | 规格真值表"本地硬保护命中→一票否决不裁" | 规格"护栏只减不增" |

仲裁器开头新增（在任何 R 之前）：
```js
// 硬保护前置：命中即否决不裁，不再进 R1-R7
if(_hardProtectionHit(L, aiData)){
  return { crop:[0,0,0,0], tag:"⏸", source:"abstain",
           reason:"硬保护命中（人脸/关节/物体/高彩），保留原图", abstained:true,
           hardProtection:true };
}
```
`_hardProtectionHit` 输入 aiData 现成信号：人脸框被裁边切穿、pose 关节点 ±4% 带被切、allBoxes 大物体被切穿、高彩显著性水平条带被裁。这些信号全部现成（与 _jointGuard/_objectGuard/高彩同源）。

### P1-5：decisionConf 拆两个语义

```js
// intentCloud 里：
cropConf: 0..100,   // 云端对"应该裁"的置信（keepOriginal=false 时有效）
keepConf: 0..100,   // 云端对"应该保留原图"的置信（keepOriginal=true 时有效）
// 缺省规则：
//   keepOriginal=true  → cropConf=0, keepConf = decisionConf||conf||50
//   keepOriginal=false → keepConf=0, cropConf = decisionConf||conf||50
// R2（听云端裁）用 cropConf；R3（强分歧弃权）用 keepConf
```

### P1-6：hasReflection 像素否决的豁免

原设计：`hasReflection===true 且 hSym<0.28 → 强制 false`。
**定稿**：
```js
// _parseIntentCloud 内：
if(C.hasReflection===true && L.signals.hSym < 0.15){        // 阈值从 0.28 降到 0.15
  // 豁免：若本地已识别为水/倒影场景（sceneType=waterscape 或 底部高色带已被 rod 识别）
  //       则不否决，保留 hasReflection=true（信任云端对小图倒影的语义判断）
  var exempt = (L.sceneType==="waterscape") || (L.signals.bottomRod === true);
  if(!exempt) C.hasReflection = false;   // 仅无豁免时才像素否决
}
```

### P1-7：开云行为变更 release note 要点（单列，不混在风险表）

开云组 snapshot 预期漂移项（需在 release note 写明"有意改进、非回归"）：

## 4. 真值表最终版（施工照此，顺序即优先级）

```js
function _arbitrateCrop(L, C, cCrop, aiData){
  var Z=[0,0,0,0];

  // 0) 硬保护前置（P1-4）
  if(L.hardProtection) return abstain("硬保护命中，保留原图");

  // 前提诊断
  var lStrong = (L.tier==="strong");
  var lWeak   = (L.tier==="weak");
  var cKeep   = (C.keepOriginal===true || C.cropIntent==="none" || C.cropIntent==="keep");
  var cCropB  = (!cKeep);
  var opp     = _directionsOppose(L.direction, C.cropIntent);

  // R1：本地强死区，云端不反对（同向或云端也裁）→ 听本地
  if(lStrong && cCropB && !opp) return pickLocal("本地强死区，云端同向确认");

  // R2：本地弱/无死区，云端强裁（cropConf>=60）→ 听云端框（cCrop=8259本地算的云端意图框）
  if(!lStrong && cCropB && C.cropConf>=60) return pickCloud(cCrop,"本地弱证据，云端强裁确认");

  // R3：本地强死区 vs 云端反对/反方向
  if(lStrong && (cKeep || opp)){
    // R3a：强分歧（本地强裁、云端强保留 keepConf>=70 且方向相反）→ 弃权
    if(opp && C.keepConf>=70) return abstain("双脑高置信方向相反，保留原图");
    // R3b：分歧但未到强 → negotiate 选优
    return negotiate(L.lCrop, cCrop, aiData);
  }

  // R4：双不裁（本地 none/weak 且云端 keepOriginal）
  if((L.tier==="none"||lWeak) && cKeep) return { crop:Z, tag:"⚖️", source:"agree", reason:"双不裁" };

  // R-conf：云端返回了但置信字段缺失（不是网络失败）→ 本地框力度减半兜底
  //   （网络失败走 _cloudFail 回退，根本不到这里）
  if(lStrong && cCropB && C.cropConf<50 && C.confMissing){
    return { crop:L.lCrop.map(v=>Math.round(v*0.5)), tag:"⚖️", source:"negotiate",
             reason:"本地强死区，云端置信缺失，力度减半" };
  }

  // R7：本地强死区，云端低置信（非缺失）→ 本地框×0.5
  if(lStrong && cCropB && C.cropConf<50){
    return { crop:L.lCrop.map(v=>Math.round(v*0.5)), tag:"⚖️", source:"negotiate",
             reason:"本地强死区，云端低置信，力度减半" };
  }

  // 兜底：未匹配 → 保守不裁
  return abstain("未匹配仲裁规则，默认不裁");
}
```

**最终真值表 7 条分支**（含硬保护）：
| 分支 | 条件 | 动作 | tag |
|---|---|---|---|
| 硬保护 | 人脸/关节/物体/高彩命中 | 否决不裁 Z | ⏸ |
| R1 | lStrong 且 cCropB 且 !opp | 本地框 | 📷 |
| R2 | !lStrong 且 cCropB 且 cropConf≥60 | 云端意图框(cCrop) | ☁️ |
| R3a | lStrong 且 opp 且 keepConf≥70 | 弃权 Z | ⏸ |
| R3b | lStrong 且 (cKeep\|\|opp) 未到R3a | negotiate 选优 | ⚖️ |
| R4 | (none/weak) 且 cKeep | 双不裁 Z | ⚖️ |
| R7/R-conf | lStrong 且 cCropB 且 cropConf<50 | 本地框×0.5 | ⚖️ |

## 7. 关云零影响三条硬规则（已逐条画调用链验证）

**snapshot.js 衔接**：分两组——关云组 crop 四元组 diff 必须=0；开云组允许漂移，每张漂移须能在 §8 分歧表找到 verdict，找不到=回归。

## 8. two-brain-diff.js 标定工具最终设计

- **输入**：139 张回归图 + D 暂存集；本地脑离线跑 planFromAnalysis（纯函数）；云端历史返回回放（不发请求）。
- **每类场景最少样本数**（红队评审补充）：portrait/food/landscape/waterscape/architecture/street/animal/night 各类 ≥15 张；**disagree-dir 分歧类 ≥20 张**（否则阈值无统计意义）；另含全白/全黑/全高彩极端图各 ≥5 张。
- **网格扫描**：strength {0.2,0.3,0.4,0.5} × strip {0.03,0.05,0.08} × cropConf/keepConf {50,60,70,80}。
- **锁定指标**：仲裁结果 vs 专家标注框 IoU≥0.75 命中率；**弃权率必须 <10%**（超=系统躺平）；hardProtection 误杀率 <2%。
- **输出**：锁定值写回本定稿 §3.2/§4 阈值表，并在纯函数顶部注释固化（日期+样本量）。
