# v12.29.0 构图与本地/云端链路研究

> 日期：2026-10-26
> 触发问题：用户实测示例「地下通道」以及大量普通照片出现“模型一直下载 / 分析后不裁 / 滤镜没套”。
> 目标：构图优先、像素先行、模型可选、云端提速，同时不牺牲人像/主体保护。

## 1. 根因

1. **模型下载抢带宽**：v12.28 首屏后自动排队下载 YOLO 10.7MB、ORT WASM 约 22MB，Service Worker 还会在 30 秒后继续预缓存人脸/姿态/分割等约 100MB。手机网络下用户点分析时，模型长期停在 loading，像素结果又被旧链路压到 16-20 秒才应用。
2. **示例预设分叉**：`loadSample()` 把旧的 `s.plan` 写入 `state.plan`，用户在真实分析完成前看到过期结论，误判算法没有工作。
3. **裁切过度“切到零”**：地下通道原图右侧约 20% 是暗墙，旧算法把右墙裁到 0，画面变窄且失去纵深；研究口径建议保留约 10-20% 暗侧负空间。
4. **滤镜闸门过严**：暗部面积大、饱和度高的“暗但有层次”照片被近黑/已浓闸门直接拦截，导致普通场景经常保持 clear。

## 2. 多轮研究结论

### 普通照片高确定性的裁切机会

- 边缘死区：单侧 3-10% 条带梯度/显著性低、不切主体，可优先裁。
- 主体过中：主体质心在中央区域且非对称画面，可向最近三分线移动。
- 地平线居中：风景/水面天空信息量明显大于地面时，把地平线压到上三分；地面更好时抬到下三分。
- 主体过小：走近或裁成 4:5/3:4，让主体面积提升到约 15-25%。
- 画幅错配：竖图优先 4:5；横图风景/街景/建筑优先 16:9；美食可 1:1/4:3。
- 暗侧呼吸：不要整面暗墙裁到 0。大侧裁时，减少侧裁，把多余量换到底部/顶部低信息区，同时保持标准画幅。

### 不裁才专业的情况

- 人像/人头特写、满框主体、合影、强对称、倒影、引导线完整、晚霞/蓝天/云海/霓虹氛围、逆光剪影、星空、刻意极简。
- 这些情况可以保留原图，但普通场景不能因为“怕裁错”而大面积不裁。

### 人景共存

- 3% 是防切像素的硬底线；审美边距单人建议 4-5%，近边脸 8%，合影 10-15%。
- 人物面积 8-25% 可环境人像轻放；25-50% 只在小腿/大腿中段落刀；超过 50% 不主动裁。

### 滤镜克制

- 自动滤镜只做轻度增强，建议强度 35-55，不再 60-78。
- 不自动加色：晚霞、逆光剪影、合影、已成黑白、文字/证件/商品图、极端过饱和。
- 夜景/暗但有层次的照片可以轻度提亮；死黑平坦照片仍不自动处理。

## 3. v12.29.0 落地

1. **像素优先**：点 AI 分析后，`analyzePixels + planFromAnalysis` 立即出方案并自动裁切/滤镜；模型/云端只后台增强，不再阻塞 16-20 秒。
2. **模型可选**：默认关闭 YOLO/人脸/姿态自动下载；Service Worker 不再后台预缓存模型。结果卡提供「开启真AI精修」，显示下载进度；已缓存模型仍可在后台复核并安全重裁。
3. **示例去陈旧**：`loadSample()` 不再写入旧 `s.plan`，示例和真实照片走同一算法。
4. **地下通道暗部呼吸**：新增 `_balanceCrop()`，普通/街景/夜景竖图若大侧裁且无上下裁，自动减少侧裁到 5-10%，把裁切量换到底部，目标 4:5。地下通道从 `[0,0,18,0]` 变为 `[0,0,10,16]`。
5. **滤镜闸门重校准**：允许 mean≥40、contrast≥45、shadowClip 较大但高光不爆的暗层次照片推荐夜景滤镜；逆光剪影、近黑、极端过饱和仍拦截。自动强度降到 35-55。
6. **云端提速**：压缩 system/user prompt 约 40%，保留全部解析字段；云端不再阻塞本地构图，返回后显示「云端建议」卡，用户可一键从原图应用，避免二次裁切和画面闪动。
