## ✨ 核心功能

### 📷 拍照（AI 拍照）
- **相机实时取景**：环境摄像头直连，取景画面 + AI 辅助线实时叠加
- **AI 构图 AI 构图模式**：AI 锁定主体、实时框出主体位置、给出"放低/退远/往左"等大白话动作引导，按下快门直接出成品（滤镜+裁切+变焦一次到位）
- **连拍选优**：长按快门连拍 5 张，按清晰度/亮度/稳定度自动选最好的一张（抗手抖）
- **定时拍照**：3/5/10 秒倒计时自拍
- **变焦特写**：1x/2x/3x 电子变焦

### 🧠 AI 构图分析（双引擎）
- **本地像素引擎（默认，不上传）**：显著性分析 + Sobel 边缘质心 + 12 条摄影构图法则（三分法/对称/引导线/黄金比例…），离线也能分析
- **云端 VLM 引擎（可选）**：经自配代理调用视觉大模型，输出语义级构图建议（场景/主体/裁切意图/滤镜推荐），弱网自动回退本地
- 分析结果卡片：画面描述 → 构图方法（含理由）→ 问题诊断 → 具体裁切方案 → 拍摄小课堂

### ✂️ 智能裁切（AI 裁切）
- **人像保护**：绝不切到头顶/下巴/手/脚，人占满屏时自动放宽保护，多人合影左右都保
- **三档裁切**：宽松（留环境）/ 标准（推荐）/ 紧凑（特写）一键切换
- **8 种比例**：自由 / 1:1 / 3:4 / 4:5 / 2:3 / 9:16 / 4:3 / 16:9
- **旋转 / 微调**：真正 90° 旋转、手柄自由拖拽（严格不出界、不超原图）
- 裁切预览：四边暗化 + 保留区虚线框，应用前看得见结果

### 🎨 滤镜与调色
- 30 款滤镜（清新/人像/胶片/黑白/氛围…），强度可调
- 专业调色：对比度/饱和度/色温/色调四维微调 + 一键增强

### 📖 新手教学（针对不会拍照的人）
- **拍摄小课堂**：构图大白话 + 分场景 ❌常见错误 vs ✅推荐拍法
- **实时动作引导条**：AI 用一句话教你怎么动（"手机放低一点""往后退一步"）
- **构图法则百科**：12 条法则配示意讲解
- **新手引导**：首次使用逐项引导，零学习成本

### 🔧 其他能力
- 原图 vs 效果对比、直方图、水平仪、光线提示
- 分析历史（最近记录）、偏好学习（记住你的裁切习惯）
- 系统分享 / 一键导出成品 / 20 步撤销
- **PWA 离线可用**：Service Worker 缓存核心资源与模型，断网也能用

## 🚀 快速开始

**在线使用（推荐）**：用手机浏览器打开
https://yyds8170-ctrl.github.io/ai-composition-tool/

**安装为 App**：打开后 → 浏览器菜单 →「添加到主屏幕」→ 全屏 App 形态使用

**本地运行**：下载最新 Release 中的 `AI-Composition-Assistant-Pro_v8.1.3.html` 单文件，双击即可在浏览器打开；相机功能需 HTTPS（GitHub Pages 已满足）。

## 📱 使用流程（30 秒上手）

1. 点「**相机**」连接摄像头（或从相册选一张照片）
2. 点「**AI 构图**」或「**分析**」→ 看 AI 怎么说（构图 + 裁切方案）
3. 按引导调整手机 → 点「**快门**」→ 成品直接带滤镜+裁切+构图优化
4. 不满意？一键重来 / 切换三档裁切 / 换滤镜，直到满意再保存分享

---

## 🔒 隐私与数据安全

- **默认零上传**：本地引擎完全在设备端运行，照片不经过任何服务器
- **云端分析为可选项**：需要时在设置中自行开启并配置「服务地址 + 访问口令」，配置保存在**浏览器本地**，项目代码不内置任何私密凭据
- **无账号、无追踪、无遥测**：不采集任何个人信息
- 分析历史与偏好仅存于本机 localStorage

## 🏗 技术架构

```
┌─────────────────────────────────────────────────┐
│            AI 构图助手 Pro（单文件 PWA）          │
│  index.html（全部 JS/CSS/示例图内联，≈1.8MB）      │
│  sw.js（Service Worker：离线缓存+模型预缓存）      │
│  manifest.webmanifest（可安装 + 图标）            │
├──────────────┬──────────────────────────────────┤
│  本地引擎     │  云端引擎（可选）                   │
│  像素显著性    │  VLM 大模型（经用户自配代理）       │
│  Sobel 质心   │  语义构图 / 场景 / 裁切意图         │
│  12 条构图法则 │  结果与本地交叉校验、失败自动回退     │
│  人像保护裁切  │  VLM 自审闭环（裁后二次确认）        │
└──────────────┴──────────────────────────────────┘
```

- **本地分析**：`analyzePixels` 像素引擎 → `planFromAnalysis` 生成构图方案
- **云端分析**：`runAIDetection` → 自配 SCF 代理 → qwen3.5-flash VLM → 语义意图 → 本地执行裁切/滤镜
- **裁切安全网**：人像保护（不切头/手脚）+ 三档裁切 + 比例守护 + 总和守门（严格 ≤70%）
- **部署**：GitHub Pages，自动构建

- **v8.1.1**（2026-09-16）：本地人像检测与裁切稳定性大修复（多轮真实图回归 + 浏览器自动化双轨，效果只增不减）。①**核心修复——静态照片人体检测改走离屏 canvas**：tfjs 的 WebGL 后端在部分 GPU（含移动端 GPU 与软件渲染）直接从 `HTMLImageElement/HTMLVideoElement` 上传纹理时结果异常，同一张人像 `detect(图片元素)` 只框到人体局部（实测仅得 0.856 的局部小框、甚至框到画面边角的飞虫），而先 `drawImage` 到等尺寸 canvas 再 `detect(canvas)` 得到正确全身框（0.917）。此前所有**静态照片**分析都受此影响，人体保护与裁切基于错误的局部框，是“裁到头/脚、构图不稳”的深层根因；现统一所有检测入口（静态分析 / AI 构图 / 虚化回退）先绘制离屏 canvas 再检测（实时取景本就用 canvas），并顺带固化视频帧、规避图片 decode 时序问题。②**修复 COCO 全身框被 MediaPipe 肩-髋局部框异步覆盖的竞态**：新增 `cocoPersonBox` 权威全身框快照，姿态/人脸/背景虚化回调在本次已检出 COCO 全身框时只更新脸部位置与肩线倾角、不再覆盖人体四边界（仅模型不可用时才用肩-髋框兜底）；同一张图跨多次分析的成品裁切从此 **bit 级稳定**。③**修复本地人体框在像素分析合并阶段被整体丢失**：补齐 `personLeft/headTop/personRight/personBottom/topBBox/personScore` 等字段合并，本地裁切人体硬保护、数据面板、调试钩子才能真正读到人体框。④本地裁切新增**人体硬保护钳制（只减不增）**：裁切线不得侵入头顶（留 ≥4%）、脚底（留 ≥6%）、身体左右（各留 ≥3%），人体贴边时宁可不裁。⑤多车辆检出正确识别“街景”（≥2 辆车且初判风景/建筑时改判街景，单车不翻盘）。⑥快门无画面拦截：未选图/未开相机时按快门不再生成 0×0 空白照片，明确提示先选图或开相机（连拍同样拦截）。**验证**：node 语法零错误；单元测试 39/39；Playwright 交互+边界 10/10（快拖/慢拖不误拍、双击重置、长按连拍、空白拦截、连点分析、横竖切换、纯色极小图）且 **0 pageerror**；34 张多类目（人像/街景/美食/建筑/水景/夜景/动物/风景）模型开启两轮，人像框全部修正为正确全身框、**6/6 人像硬保护零违规**（头顶贴边、脚底贴底案例均正确救回）、非人像裁切零回退、连续 6 轮成品裁切完全一致；关闭模型降级路径 0 错误、0 裁切越界（纯像素保守对称裁切）。
