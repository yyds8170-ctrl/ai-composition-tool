# AI 构图助手 Pro（PWA）

专业 AI 构图取景器 · 手机 App 形态网页应用

## 功能
- 📷 相机实时取景（需 HTTPS，手机授权摄像头）
- 🤖 AI 构图分析（本地像素分析，不上传，无联网）
- 🎨 18 款胶片滤镜 + 强度调节
- ✂️ 智能裁切（比例/旋转/输出尺寸）
- 🖼️ 原图 vs 效果对比、直方图、水平仪
- 📚 12 条摄影构图法则百科

## 使用
直接访问：`https://yyds8170-ctrl.github.io/ai-composition-tool/`
手机浏览器打开后 → 添加到主屏幕 → 全屏 App 形态使用。

全部文件本地运行，照片不上传任何服务器。
