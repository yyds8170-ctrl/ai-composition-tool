## 待补验项 ①：真实相机帧流 + UI 渲染时序

- **验证目的**：确认在真实手机相机帧流下，本地推理（YOLO11n onnx / MediaPipe face_detection / pose）与浮层引导文案、保护带、cropBox 叠加的渲染时序无明显掉帧/延迟/错位。
- **验证方法**：
  1. iPhone（iOS Safari）与 Android（Chrome）各一台，最新系统；
  2. 站点加到主屏 PWA 后冷启动，进入取景器，对准静止人像 / 走动人像 / 双人场景各 30 秒；
  3. 观察浮层文案切换、保护带绘制、前后对比叠加是否与画面同步；
  4. 录屏 60fps 回看，统计首帧引导出现延迟与文案跳变次数。
- **通过标准**：
  - 首帧引导 ≤ 800ms（4G/Wi-Fi 首次加载后）；
  - 浮层无残影、无重叠错位；
  - 文案切换无高频抖动（同一结论持续 ≥ 3 帧防抖已在本地实现，真机复测确认）；
  - 无控制台报错 / 无白屏 / 无 SW 意外注册失败。
- **当前状态**：⬜ 未补验（headless 软渲染已过，但真机 GPU/相机管线未验证）。

## 待补验项 ②：多主体状态标签端到端实拍触发

- **验证目的**：确认 `_classifyMulti` 在真实相机帧流下，干净双人 →「双人构图」、三人合影 →「三人合影」标签能正确端到端触发；人群/单人/远人/叠站/非人像场景一律不出现标签。
- **验证方法**：
  1. 真机取景器分别拍摄：干净双人并排（间距正常）、干净三人并排、单人+路人（主次比悬殊）、≥4 人群、两人紧贴叠站、夜景双人、建筑前双人合影；
  2. 观察浮层角标是否按预期出现「双人构图」/「三人合影」或保持 null；
  3. 对照纯函数单测用例（nP∈{2,3}、maxH≥0.25、secH/mainH≥0.55、|cx差|≥0.12、score≥0.5、场景白名单）逐一核对。
- **通过标准**：
  - 干净双人/三人正确出标签（conf 约 0.7）；
  - 路人、人群、叠站、远人、夜景/建筑/花/宠物场景一律 null；
  - 标签出现/消失无闪烁（3 帧防抖生效）；
  - 标签不回写 crop（裁切框与单人模式一致）。
- **当前状态**：⬜ 未补验（单测 383→404 已覆盖纯函数正负例，真机端到端待拍）。

## 待补验项 ③：离线冷启动 SW 模型预缓存

- **验证目的**：确认断网冷启动时，Service Worker 预缓存（延迟 30s 启动、fetch 唤醒续跑）能把 YOLO11n onnx / onnxruntime wasm / MediaPipe 本地模型缓存到足够比例，二次离线打开核心功能可用。
- **验证方法**：
  1. 首次联网打开站点，等待 SW 激活 + 30s 预缓存 + 任意 fetch 唤醒续跑；
  2. 飞行模式冷启动（杀进程后重开），进入取景器；
  3. 观察本地检测是否仍能加载（YOLO11n / face_detection / pose），裁切与引导是否工作；
  4. 二次冷启动重复一次，确认缓存命中率。
- **通过标准**：
  - 离线冷启动首页不白屏、不报错；
  - 本地检测能加载（允许首次离线未缓存完时回退 CDN 不可用，但 UI 不弹窗）；
  - 云端不可用时静默降级本地，无 alert / 无红色错误条；
  - SW 更新条（AIC_SW_UPDATE）在版本升级时正常弹出。
- **当前状态**：⬜ 未补验（本地同源模型路径已就位，真机 SW 生命周期待观测）。
