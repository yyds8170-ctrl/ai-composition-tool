日期：2026-10-26
目的：在无 CLOUD_TOKEN 的环境验证“像素先落地 → 云端建议卡 → 从原图应用”的新交互。
方法：本地 HTTP 服务同时提供静态页和 POST /chat/completions，返回严格 JSON 的云端方案（keepOriginal=true）。
结果：

- 点「应用云端构图」后恢复原图 800×516、noCrop=true，状态“已应用云端建议：保留原图”。
- 页面控制台 0 错误。
局限：mock 不能验证真实 VLM 的场景/裁切语义、时延与 50 张成功率；真实云端 50 张仍需 CLOUD_TOKEN。
