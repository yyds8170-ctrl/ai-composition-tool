- **验证目的**：确认在真实手机相机帧流下，本地推理（YOLO11n onnx / MediaPipe face_detection / pose）与浮层引导文案、保护带、cropBox 叠加的渲染时序无明显掉帧/延迟/错位。
- **当前状态**：⬜ 未补验（headless 软渲染已过，真机 GPU/相机管线未验证）。

## 待补验项 ②：多主体状态标签端到端实拍触发

- **验证目的**：确认 `_classifyMulti` 在真实相机帧流下，干净双人 →「双人构图」、三人合影 →「三人合影」标签能正确端到端触发。
- **当前状态**：⬜ 未补验（单测 404 已覆盖纯函数正负例，真机端到端待拍）。

## 待补验项 ③：离线冷启动 SW 模型预缓存

- **验证目的**：确认断网冷启动时，Service Worker 预缓存能把 YOLO11n onnx / onnxruntime wasm / MediaPipe 本地模型缓存到足够比例，二次离线打开核心功能可用。
- **当前状态**：⬜ 未补验（本地同源模型路径已就位，真机 SW 生命周期待观测）。

## 待补验项 ④（v11.7.1 新增）：「?」悬浮按钮拖动交互

- **验证目的**：确认新手引导「?」按钮在真机上可自由拖动到屏幕任意位置，位置记忆持久化，双击复位；拖动时不误触点击（4px 阈值）。
- **验证方法**：
  1. 手机浏览器打开站点，长按「?」按钮拖动到屏幕右下角；
  2. 刷新页面，确认按钮仍在右下角（localStorage `helpFabPos`）；
  3. 双击按钮，确认复位到默认位置；
  4. 单击按钮，确认新手引导面板正常弹出（不触发拖动）。
- **通过标准**：拖动流畅无卡顿；位置刷新后保留；双击复位生效；单击/拖动不误触。
- **当前状态**：⬜ 未补验（桌面 puppeteer 已验证逻辑，真机触摸事件待测）。
